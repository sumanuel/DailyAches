# DailyAches

App Expo/React Native para registrar personas, tipos de dolor, historial, progreso y estadisticas.

## Lectura recomendada

- Contexto funcional y tecnico: CONTEXTO_PROYECTO.md
- Arranque operativo: ARRANQUE_RAPIDO.md
- Matriz app/backend: MATRIZ_APP_BACKEND.md
- Roadmap historico: roadmap.md

## Stack

- Expo SDK 54
- React 19
- React Native 0.81
- react-native-paper
- React Navigation
- API propia Dailyaches-api

## Comandos rapidos

```bash
npm install
npm run start
npm run android
npm run web
```

## Estado de la documentacion

Usa CONTEXTO_PROYECTO.md para mapa del repo, ARRANQUE_RAPIDO.md para operacion y MATRIZ_APP_BACKEND.md para contratos con la API.
